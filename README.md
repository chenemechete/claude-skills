# Claude Skills — UI & Product Psychology

A collection of Claude Cowork skills for applying behavioral science and UI design frameworks to product work.

---

## Skills

### 🎨 ui-psychology
**The Product UI Framework (MSVHD)**

Audit, design, or improve user interfaces using five evidence-backed pillars:

| Pillar | Focus | Core Question |
|--------|-------|---------------|
| **M — Message** | Copywriting | Why should the user care, right now? |
| **S — Structure** | Layout | Is the screen easy to understand at a glance? |
| **V — Visibility** | Accessibility | Can everyone see, reach, and use it? |
| **H — Hierarchy** | Emphasis | Is the most important thing unmissable? |
| **D — Delight** | Reward | Does the screen make the user feel something meaningful? |

Use this skill to: audit a UI, redesign a screen, or get structured design feedback grounded in Gestalt psychology, Cognitive Load Theory, and Self-Determination Theory.

---

### 🧠 product-psychology
**Behavioral Science for Product Teams**

Diagnose *why* users aren't completing a desired action and get specific, framework-backed recommendations.

Covers 21 behavioral science frameworks including:
- Fogg Behavior Model (B = MAP)
- COM-B diagnostic triage
- Loss Aversion, Anchoring, Scarcity, Social Proof
- Sunk Cost, Goal Gradient, Zeigarnik Effect
- Endowment Effect, IKEA Effect, Hyperbolic Discounting
- Variable Reward, Commitment & Consistency, Decision Fatigue
